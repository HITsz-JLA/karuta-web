# 在线歌牌故障日志

在线服务由 `karuta-web.service` 托管，标准输出和错误输出写入 systemd journal。服务端会额外写入一行一个事件的 `[karuta-online]` 日志，用于定位 WebSocket 断线、刷新恢复和音频请求问题。

## 记录内容

- `ws.connected`、`ws.disconnected`、`ws.error`、`ws.heartbeat_timeout`：连接建立、断开、错误和心跳超时。
- `resume.accepted`、`resume.rejected`、`resume.expired`、`ws.replaced`：刷新恢复、恢复失败、恢复过期和旧连接被替换。
- `round.started`、`claim.received`、`round.resolved`：回合、抢牌和结算上下文。
- `audio.served`、`audio.miss`、`audio.range_rejected`：音频成功、凭证失效、资源缺失和 Range 请求异常。

日志不记录恢复令牌、音频令牌、管理员密码或完整请求内容。

## 服务器查看

```bash
journalctl -u karuta-web.service -o cat --since "10 minutes ago"
journalctl -u karuta-web.service -o cat -f
journalctl -u karuta-web.service -o cat --since "2026-09-10 20:00" | grep '\[karuta-online\]'
```

报告故障时，尽量提供北京时间、房间码、双方席位、听到音频的大致时间，以及是否刷新过页面。按这些信息可以从日志中关联同一回合的连接、音频和抢牌事件。
